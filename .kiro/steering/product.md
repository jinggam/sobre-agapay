# Product: Sobre

Sobre ("envelope") is a mobile-first web app that acts as a safe digital envelope
for 4Ps (Pantawid Pamilyang Pilipino Program) household papers.

## Who it is for
- Primary: 4Ps grantees (usually mothers) managing papers for several children.
- Secondary: Parent Leaders, barangay staff, City/Municipal Links.

## Core jobs
1. Scan a paper, let Lumen OCR read it, let the user confirm, and file it.
2. Show each family member's compliance status and remind the user before deadlines.
3. Explain any saved paper in plain Filipino using Lumen AI Chat, with read-aloud.

## Product rules
- Filipino (Tagalog) first, English toggle. Plain words, no jargon.
- Every icon has a word label. Status uses color + icon + word, never color alone.
- One main action per screen. Touch targets at least 48px. Base font 18px.
- The user always checks and can correct what the AI read before saving.
- Never store the cash card PIN. Data stays on the device by default.
- The app gives guidance, not official DSWD decisions. Always point to the
  City/Municipal Link for official concerns.
